📋 SOLUTION RAPIDE (2 ÉTAPES)

ÉTAPE 1 - SERVEUR :
───────────────────

Windows :
  1. Ctrl + C (arrêter serveur)
  2. Double-cliquer : force-clean.bat
  3. Attendre "VITE ready"

Mac/Linux :
  1. Ctrl + C (arrêter serveur)
  2. Terminal : ./force-clean.sh
  3. Attendre "VITE ready"

═══════════════════════════════════════════════════════════════

ÉTAPE 2 - NAVIGATEUR : ⚠️ LA PLUS IMPORTANTE !
──────────────────────────────────────────────

Option A - Mode Incognito (LE PLUS SIMPLE) :
  1. Ctrl + Shift + N (navigation privée)
  2. http://localhost:3000
  3. F12 → Vérifier console
  
  Si console propre → SUCCÈS ! ✅
  Si erreur persiste → Essayer Option B

Option B - Vider cache (SI OPTION A NE MARCHE PAS) :
  1. http://localhost:3000
  2. F12 (DevTools)
  3. Clic DROIT sur bouton refresh 🔄
  4. Sélectionner "Vider le cache et actualiser"
  5. Fermer DevTools
  6. Ctrl + Shift + R (5 fois)

Option C - Vider tout (SI OPTION B NE MARCHE PAS) :
  1. F12 → Onglet "Application"
  2. "Storage" (menu gauche)
  3. "Clear site data"
  4. "Clear all"
  5. Fermer tous les onglets localhost:3000
  6. Fermer navigateur complètement
  7. Rouvrir
  8. http://localhost:3000
