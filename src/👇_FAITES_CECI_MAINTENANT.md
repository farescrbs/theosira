# 👇 FAITES CECI MAINTENANT

## 1. Ouvrir le Terminal

**Windows :**
- Appuyez sur `Windows + R`
- Tapez `cmd`
- Appuyez sur `Entrée`

**Mac :**
- Appuyez sur `Cmd + Espace`
- Tapez `Terminal`
- Appuyez sur `Entrée`

**VS Code :**
- Appuyez sur `Ctrl + ù`

---

## 2. Taper cette commande

```bash
npm run dev
```

Appuyez sur `Entrée`.

---

## 3. Ouvrir votre navigateur

Ouvrez Chrome, Firefox ou Edge.

Dans la barre d'adresse :
```
http://localhost:5173/
```
