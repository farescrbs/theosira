Méthode 1 - Page Dédiée (Recommandé) :
───────────────────────────────────────

1. Ouvrir App.tsx

2. Remplacer le contenu par :

   import GraalDemo from './GraalDemo';
   
   export default function App() {
     return <GraalDemo />;
   }

3. Sauvegarder

4. Lancer : npm run dev


Méthode 2 - Intégration THESORIA :
──────────────────────────────────

1. Dans App.tsx, ajouter l'import :

   import { GraalDashboard } from './components/graal/GraalDashboard';

2. Ajouter dans la navigation :

   <button onClick={() => setView('graal')}>AI Engine</button>

3. Ajouter dans le contenu :

   {view === 'graal' && <GraalDashboard />}
