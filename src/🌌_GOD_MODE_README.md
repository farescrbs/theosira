### RPC Configuration

Pour **optimiser vitesse** et **fiabilité** :

1. Créer compte **Alchemy** (gratuit) : alchemy.com
2. Créer app "Ethereum Mainnet"
3. Copier clé API
4. Ouvrir `backend\.env`
5. Remplacer `ETH_RPC_URL=...` par votre clé

**Bénéfices** :
- Requêtes illimitées
- Latence réduite
- Fiabilité 99.9%
- Support archive node

---

### Gas Optimization

Le bot **optimise automatiquement** le gas :

- **EIP-1559** : Base fee + Priority fee
- **Gas Estimation** : Simulation avant exécution
- **Retry Logic** : Si gas trop élevé, attendre
- **Flashbots** : Transactions privées (pas de front-run)

Configuration dans `backend\.env` :

```env
MAX_GAS_PER_TX=0.01      # Max gas par transaction (ETH)
MAX_DAILY_GAS=0.1        # Max gas par jour (ETH)
MIN_BALANCE_KEEP=0.05    # Balance minimum à garder (ETH)
```

## 🎓 STRATÉGIES DÉTAILLÉES

### 1. Flash Loans ($0 capital)

**Principe** :
1. Emprunter $1,000,000 USDC (Aave)
2. Acheter ETH sur Uniswap
3. Vendre ETH sur Sushiswap
4. Rembourser $1,000,000 USDC
5. Profit = Spread - Gas

**Profit** : $200-1,500/trade  
**Fréquence** : 5-20/jour  
**Risque** : Très faible (simulation avant)

---

### 2. MEV Front-Running ($0 capital)

**Principe** :
1. Scanner mempool Ethereum
2. Détecter gros swap profitable
3. Envoyer transaction avec gas +10%
4. Transaction exécutée AVANT le swap
5. Profit = Spread

**Profit** : $100-800/trade  
**Fréquence** : 10-30/jour  
**Risque** : Moyen (gas wars)

---

### 3. Cross-Chain Arbitrage ($0.01 ETH)

**Principe** :
1. Scanner prix ETH sur 10 chains
2. Trouver spread > 0.5%
3. Acheter sur chain A
4. Bridge vers chain B
5. Vendre sur chain B
6. Profit = Spread - Bridge fees - Gas

**Profit** : $150-600/trade  
**Fréquence** : 3-10/jour  
**Risque** : Faible (bridge testé)

---

### 4. Liquidation Hunting ($0.01 ETH)

**Principe** :
1. Scanner positions Aave/Compound
2. Trouver Health Factor < 1.05
3. Liquider position
4. Recevoir bonus liquidation (5-10%)
5. Profit = Bonus - Gas

**Profit** : $300-1,200/trade  
**Fréquence** : 2-8/jour  
**Risque** : Très faible (profit garanti)

---

### 5. JIT Liquidity ($0.01 ETH)

**Principe** :
1. Détecter gros swap dans mempool
2. Ajouter liquidité Uniswap V3 juste avant
3. Swap exécuté (fees collectées)
4. Retirer liquidité juste après
5. Profit = Fees - Gas

**Profit** : $50-300/trade  
**Fréquence** : 20-50/jour  
**Risque** : Faible (IL négligeable)

- Marché calme : 1-3 opportunités/heure

### "Connection refused"

**Problème** : RPC endpoint down  
**Solution** :
1. Vérifier `backend\.env`
2. Tester RPC : `curl <RPC_URL>`
3. Changer RPC si besoin

RPCs publics :
```
Ethereum: https://eth.llamarpc.com
Polygon: https://polygon-rpc.com
Arbitrum: https://arb1.arbitrum.io/rpc
```
