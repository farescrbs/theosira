## 💎 AUTO-BACKUP SYSTEM - DÉTAILS

### Configuration

**Dans `backend/.env`** :
```env
# Auto-Backup Configuration
BACKUP_WALLET_ADDRESS=0x...        # Wallet sécurisé
BACKUP_THRESHOLD=0.1               # Seuil (0.1 ETH)
BACKUP_PERCENTAGE=50               # 50% vers backup
AUTO_BACKUP_ENABLED=true           # Activé

# Alertes
DISCORD_WEBHOOK=https://discord.com/api/webhooks/...
TELEGRAM_WEBHOOK=...
```

### Fonctionnement

```
[1] Bot génère profits
       ↓
[2] Balance > 0.1 ETH détectée
       ↓
[3] Calcul 50% du montant
       ↓
[4] Transaction vers wallet backup
       ↓
[5] Confirmation on-chain
       ↓
[6] Alerte Discord/Telegram
       ↓
[7] Historique sauvegardé
```

### Sécurité

**WALLET BACKUP** :
- ✅ Complètement séparé
- ✅ Clés stockées différemment
- ✅ Hardware wallet recommandé
- ✅ Multi-sig possible

**VÉRIFICATIONS** :
- ✅ Simulation avant envoi
- ✅ Gas check
- ✅ Balance suffisante
- ✅ Confirmation on-chain

**HISTORIQUE** :
- ✅ Tous transfers logués
- ✅ Fichier `backup_history.json`
- ✅ Timestamps précis
- ✅ Tx hashes stockés
