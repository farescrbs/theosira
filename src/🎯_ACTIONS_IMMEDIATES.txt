  ⚠️ EN CAS DE PROBLÈME
═══════════════════════════════════════════════════════════════════════

   ❌ Build échoue :
      → npm ci
      → npm run build

   ❌ Vercel non trouvé :
      → npm install -g vercel

   ❌ Mémoire insuffisante :
      → set NODE_OPTIONS=--max-old-space-size=4096
      → npm run build

   ❌ Dépendances corrompues :
      → rmdir /s /q node_modules
      → del package-lock.json
      → npm install
