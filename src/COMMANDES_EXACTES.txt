┌──────────────────────────────────────────────────────────────────────┐
│ Nettoyer et Réinstaller                                             │
└──────────────────────────────────────────────────────────────────────┘

Windows :
─────────
rmdir /s /q node_modules
del package-lock.json
npm install
npm run build


Linux/Mac :
───────────
rm -rf node_modules package-lock.json
npm install
npm run build


┌──────────────────────────────────────────────────────────────────────┐
│ Augmenter la Mémoire (Si "Out of Memory")                           │
└──────────────────────────────────────────────────────────────────────┘

Windows :
─────────
set NODE_OPTIONS=--max-old-space-size=4096
npm run build


Linux/Mac :
───────────
NODE_OPTIONS=--max-old-space-size=4096 npm run build


┌──────────────────────────────────────────────────────────────────────┐
│ Vérifier les Versions                                               │
└──────────────────────────────────────────────────────────────────────┘

node --version

npm --version

vercel --version


┌──────────────────────────────────────────────────────────────────────┐
│ Nettoyer le Cache Vite                                              │
└──────────────────────────────────────────────────────────────────────┘

Windows :
─────────
rmdir /s /q node_modules\.vite
rmdir /s /q dist


Linux/Mac :
───────────
rm -rf node_modules/.vite dist


═══════════════════════════════════════════════════════════════════════
  📦 DÉPLOIEMENT DU SMART CONTRACT FLASHBOT
═══════════════════════════════════════════════════════════════════════

┌──────────────────────────────────────────────────────────────────────┐
│ Étape 1 : Aller dans le dossier contracts                           │
└──────────────────────────────────────────────────────────────────────┘

cd contracts


┌──────────────────────────────────────────────────────────────────────┐
│ Étape 2 : Installer les dépendances                                 │
└──────────────────────────────────────────────────────────────────────┘

npm install --legacy-peer-deps


┌──────────────────────────────────────────────────────────────────────┐
│ Étape 3 : Configurer la clé privée                                  │
└──────────────────────────────────────────────────────────────────────┘

Créer un fichier .env dans contracts/ :

echo PRIVATE_KEY=VOTRE_CLE_PRIVEE_ICI > .env

⚠️ REMPLACER "VOTRE_CLE_PRIVEE_ICI" par votre vraie clé !


┌──────────────────────────────────────────────────────────────────────┐
│ Étape 4 : Déployer sur Polygon                                      │
└──────────────────────────────────────────────────────────────────────┘

npm run deploy:polygon

OU

npx hardhat run scripts/deploy-flashbot.js --network polygon


┌──────────────────────────────────────────────────────────────────────┐
│ Étape 5 : Copier l'adresse du contrat                               │
└──────────────────────────────────────────────────────────────────────┘

Vous verrez dans le terminal :

   ✅ FlashBot deployed to: 0xABC123...

Copier cette adresse !


┌──────────────────────────────────────────────────────────────────────┐
│ Étape 6 : Mettre à jour deployment.json                             │
└──────────────────────────────────────────────────────────────────────┘

Retour au dossier racine :

cd ..


Éditer public/contracts/deployment.json :

{
  "networks": {
    "polygon": {
      "FlashBot": "0xABC123...",  ← Coller l'adresse ici
      "deployedAt": "2024-12-27T..."
    }
  }
}


┌──────────────────────────────────────────────────────────────────────┐
│ Étape 7 : Rebuild et Redéployer                                     │
└──────────────────────────────────────────────────────────────────────┘

npm run build

vercel --prod
