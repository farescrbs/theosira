═══════════════════════════════════════════════════════════════════════
  ❓ RÉSOLUTION DES PROBLÈMES
═══════════════════════════════════════════════════════════════════════

❌ Erreur "dist not found" :
   Solution : npm run build

❌ Erreur "vercel not found" :
   Solution : npm install -g vercel

❌ Build échoue (mémoire) :
   Solution : set NODE_OPTIONS=--max-old-space-size=4096
             npm run build

❌ Erreur dépendances :
   Solution : rmdir /s /q node_modules
             del package-lock.json
             npm install
