# ⚡ 3 CHOSES À SAVOIR

## 1️⃣ `.env.example` = PARAMÈTRES

**Format :**
```env
CLE=valeur
```

**Exemple :**
```env
VITE_APP_NAME=THESORIA
VITE_API_URL=https://api.example.com
```

**PAS de commandes, PAS de code !**

---

## 2️⃣ Terminal = COMMANDES

**Exemple :**
```bash
npm run dev
npm install
```

**Tapez dans le terminal, PAS dans un fichier !**

---

## 3️⃣ Fichiers .sol / .tsx = CODE

**Exemple Solidity :**
```solidity
pragma solidity ^0.8.10;
contract MyContract { ... }
```

**Exemple React :**
```typescript
import React from 'react';
export default function App() { ... }
```

**Code dans des fichiers, PAS dans `.env.example` !**

---

## 🚀 LANCER THESORIA

**Dans le terminal :**
```bash
npm run dev
```

**Puis ouvrir :** `http://localhost:5173/`

---

💎 **C'est tout !** 💎
