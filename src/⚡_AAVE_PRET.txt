═══════════════════════════════════════════════════════════════════════
  ⚙️ CONFIGURATION
═══════════════════════════════════════════════════════════════════════

1. Créer .env :
   ────────────
   cp .env.example .env


2. Remplir variables :
   ────────────────────
   VITE_AAVE_API_URL=https://aave-api-v2.aave.com
   VITE_WALLET_CONNECT_PROJECT_ID=your_id
   VITE_ETH_RPC_URL=https://eth-mainnet.g.alchemy.com/v2/YOUR_KEY


3. Wallet Connect Project ID :
   ────────────────────────────
   → https://cloud.walletconnect.com/
   → Create Project
   → Copier le Project ID
