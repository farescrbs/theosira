═══════════════════════════════════════════════════════════════════════
  ⚙️ CONFIGURATION NÉCESSAIRE
═══════════════════════════════════════════════════════════════════════

Pour activer GitHub Actions, vous devez ajouter 3 secrets dans GitHub :

   GitHub Repo → Settings → Secrets → Actions → New secret

   1️⃣  VERCEL_TOKEN          (Token d'API Vercel)
   2️⃣  VERCEL_ORG_ID         (ID organisation)
   3️⃣  VERCEL_PROJECT_ID     (ID projet)


═══════════════════════════════════════════════════════════════════════
  🔑 OBTENIR LES SECRETS
═══════════════════════════════════════════════════════════════════════

VERCEL_TOKEN :
──────────────
   1. https://vercel.com/account/tokens
   2. Create Token
   3. Copier le token


VERCEL_ORG_ID et VERCEL_PROJECT_ID :
─────────────────────────────────────
   Méthode 1 - Via CLI :
      vercel link
      cat .vercel/project.json

   Méthode 2 - Dashboard :
      Vercel → Project → Settings → General
      Copier Project ID et Team ID

Workflow 1 : vercel-deploy.yml
──────────────────────────────
   Déclenché par :
      - Push sur main/master
      - Déclenchement manuel

   Actions :
      ✅ Checkout code
      ✅ Install Node.js 18
      ✅ Install dépendances
      ✅ Build (npm run build)
      ✅ Deploy Vercel Production
      ✅ Notification GitHub


Workflow 2 : ci-cd.yml
──────────────────────
   Jobs :
      1. Lint     → ESLint + TypeScript check
      2. Build    → npm run build
      3. Deploy   → Vercel (seulement main/master)
