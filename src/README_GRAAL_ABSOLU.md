## 🚀 DÉPLOIEMENT EN 5 MINUTES

### Quick Start

```bash
# 1. Clone le repo
git clone https://github.com/thesoria/platform.git
cd platform

# 2. Install dependencies
npm install

# 3. Configure environment
cp .env.example .env
# Edit .env avec vos clés

# 4. Deploy smart contracts
cd contracts
npx hardhat run scripts/deploy.js --network gnosis

# 5. Start dev server
npm run dev
```

### Production Deployment

```bash
# Install Vercel CLI
npm i -g vercel

# Login
vercel login

# Deploy
vercel --prod
```

**C'est fait ! Votre plateforme est en production.**
