5. 🔧 /index.html                → ✅ CORRIGÉ !

═══════════════════════════════════════════════════════════════════════
  📝 POURQUOI main.tsx ÉTAIT NÉCESSAIRE ?
═══════════════════════════════════════════════════════════════════════

Sans main.tsx :
───────────────
   index.html → App.tsx directement
                └─> ❌ ReactDOM jamais initialisé
                └─> ❌ App jamais monté dans le DOM
                └─> ❌ Build échoue


Avec main.tsx :
───────────────
   index.html → main.tsx → Initialise ReactDOM
                         └─> Importe App.tsx
                         └─> Monte <App /> dans #root
                         └─> ✅ Build réussit !


═══════════════════════════════════════════════════════════════════════
  📦 CONTENU DE main.tsx (NOUVEAU FICHIER)
═══════════════════════════════════════════════════════════════════════

import React from 'react';
import ReactDOM from 'react-dom/client';
import App from './App';
import './styles/globals.css';

ReactDOM.createRoot(document.getElementById('root')!).render(
  <React.StrictMode>
    <App />
  </React.StrictMode>
);


Ce fichier :
   ✅ Importe React et ReactDOM
   ✅ Importe le composant App
   ✅ Importe les styles globaux
   ✅ Crée la racine React
   ✅ Monte <App /> dans <div id="root">
