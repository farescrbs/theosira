# 👉 LIRE CECI SVP

## 🎯 **POUR LANCER THESORIA :**

### **NE PAS modifier `.env.example`**

### **À LA PLACE :**

**1. Ouvrir le terminal**

```
Windows : Windows + R → cmd → Entrée
Mac     : Cmd + Espace → Terminal → Entrée
VS Code : Ctrl + ù
```

**2. Taper cette commande**

```bash
npm run dev
```

**3. Ouvrir le navigateur**

```
http://localhost:5173/
```
